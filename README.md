# Hybrid-models-for-forecasting-macroeconomic-indicators
Прогнозирование ВВП с использованием классических и гибридных моделей: ARIMA, Random Forest и гибрид ARIMA-RF. Проект для анализа и сравнения подходов к макроэкономическому моделированию.

Проект выполнен в рамках курсовой работы по теме **«Гибридные модели прогнозирования макроэкономических показателей»**.

## Цели и задачи

**Цель:**  
Разработка и сравнительный анализ гибридных моделей прогнозирования макроэкономических показателей, объединяющих традиционные эконометрические подходы с методами машинного обучения.

**Задачи:**
- провести предварительную обработку и анализ временного ряда ВВП;
- реализовать пошаговое (walk-forward, expanding window) прогнозирование;
- сравнить модели по точности уровня и направлению изменений;
- проанализировать остатки и интерпретировать результаты.

## Используемые модели

### 1. ARIMA
- автоматический подбор параметров с помощью `auto_arima`;
- прогнозирование логарифмических разностей;
- обратное преобразование к уровню ряда;
- анализ остатков (ACF, PACF, Ljung–Box).

### 2. Random Forest
- моделирование логарифмических разностей временного ряда;
- создание лаговых признаков;
- подбор гиперпараметров через `GridSearchCV`;
- прогнозирование в режиме expanding window.

### 3. Гибридная модель ARIMA–RF
- базовый прогноз уровня с помощью ARIMA;
- остатки ARIMA моделируются Random Forest;
- гибридный прогноз как сумма ARIMA-прогноза и прогноза остатков;
- остатки обновляются пошагово в процессе walk-forward прогнозирования.

##  Метрики качества

Для оценки моделей используются:

- MAE (%) — средняя абсолютная ошибка (Mean Absolute Error)
- RMSE (%) — среднеквадратическая ошибка (Root Mean Squared Error)
- MAPE (%) — средняя абсолютная процентная ошибка (Mean Absolute Percentage Error)
- Directional Accuracy (DA) — статистика направленной точности прогнозов;
- Confusion Matrix для анализа правильности предсказания направления изменений.


## Результаты исследования
Значение средней абсолютной ошибки (MAE) для базовой модели ARIMA составило 0.346%, для модели Random Forest — 0.383%, тогда как для гибридной модели ARIMA-RF данный показатель снизился до 0.31%. Таким образом, разработанная гибридная модель обеспечила повышение точности прогнозирования примерно на 10% по сравнению с традиционной эконометрической моделью и на 20% по сравнению с моделью машинного обучения. Аналогичная кратина наблюдается и с другими метриками.

Гибридная модель ARIMA-RF достигает значительного выигрыша в точечной точности, но при этом частично теряет в качестве предсказания направления по сравнению с ARIMA.
